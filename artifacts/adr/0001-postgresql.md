# ADR-001: Використати PostgreSQL для збереження даних

- Статус: Прийнято
- Дата: 2026-03-14

## Контекст
Для електронного журналу необхідно надійне сховище реляційних даних для збереження інформації про студентів, оцінки та розклад.

## Варіанти
- PostgreSQL
- MongoDB

## Рішення
Обрано реляційну СУБД PostgreSQL завдяки підтримці складних транзакцій та цілісності даних.

## Наслідки
- Плюси: Висока надійність та підтримка ACID.
- Мінуси: Потребує налаштування міграцій схем.
- Атрибути якості: Надійність, Супровідність
